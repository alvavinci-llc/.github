# alvavinci LLC

**AI agents built into real business workflows — from discovery to production.**

alvavinci LLC is a technology company in Oita, Japan. We work inside client teams to put AI agents into the work itself: mapping how things actually get done, designing the agent and the systems around it, building with coding agents (Claude Code, Codex), and running it in production. We also run our own businesses with AI agents.

- **AI Engineering** — AI agents inside business tools (Slack, Outlook, Zoom, SharePoint, Asana, internal systems), LLM applications over company documents and data, agent-driven operations, and the APIs and AWS / Azure infrastructure behind them
- **How we work** — fully remote from Japan (JST, UTC+9), async-first in English, meetings available in Japanese
- **Engagements** — contract and project-based work for clients in Japan and overseas

合同会社alvavinciは、お客様のチームに入り込み、AIエージェントを実際の業務に組み込む技術会社です（大分）。業務の整理から設計・開発・本番運用まで一貫して対応します。国内・海外の案件にフルリモートで対応しています。
